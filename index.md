## 📖 How to Use Grade

1. **Create a New Project:** After launching Grade, select "New Project" from the main menu. This will allow you to start designing your environment.

2. **Choose Environment Settings:** Use the settings panel to select terrain type, animation speed, and other features for your dynamic environment.

3. **Add Models:** You can add various models of animals and humans. Simply drag and drop from the model library into your project.

4. **Save Your Work:** Regularly save your progress using the "Save" option. This will help you avoid losing any data.

5. **Test Your Environment:** Use the simulation feature to see how your robots interact with the environment. Adjust settings as needed to refine the experience.
